# Лабораторная работа №3 — Вёрстка макета с помощью Flexbox и Grid

Вариант 20 — Футуролог и концепт-художник (технологии и прогнозы)

## Описание
Страница из ЛР №2, дополненная адаптивным меню навигации, карточками технологий
будущего (Flexbox) и дашбордом прогнозов по сферам (CSS Grid). Полностью
адаптивна для планшетов и мобильных устройств.

## Новые элементы
- Flexbox: меню навигации (`<nav>`), карточки «Технологии будущего»
- CSS Grid: дашборд «Прогнозы по сферам» (3 блока)
- Медиа-запросы: breakpoints 768px (планшет) и 480px (мобильный)
- Семантика: `<mark>` для выделения ключевых слов в прогнозах
- `box-sizing: border-box` для корректного расчёта размеров с Flexbox/Grid
